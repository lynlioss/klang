# Validation

The first 106,004,738-byte APK was successfully tried on Lynli's phone. Its size included 68,434,456 compressed DEX bytes and 36,178,133 asset bytes. The asset pack accidentally included KYOTO twice. The source now contains exactly three M4As (about 23 MB), with matching embedded title, artist, album and artwork, and the full extended icon dependency has been replaced by selected vectors.

Version 0.2 is compiled with SDK 37.2/AGP 9.5.1 and requires Android 16. The distribution build uses R8 code shrinking, omits Compose preview tooling, and keeps the existing debug signing identity for update installation. Music is preserved without transcoding. Resource shrinking is disabled: the ARM64 packaging tool did not produce the optimized resource output required by AGP 9, and APK validation detected a missing manifest.

Build, lint, focused metadata tests, package/signing verification, and the download response are checked before distributing the updated APK. No ADB-connected device is available from proot. The revised visual layout, touch seeking, cover colors and permission refresh require a new on-phone trial.

The delivered 0.2.0 APK is 27,775,443 bytes (27.8 decimal MB). It has three unique M4As, a parsed Android manifest, a complete resource table, valid ZIP CRCs, aligned entries, and a verified APK v3 signature matching the first installed test APK. SHA-256: `cd18e50e4d080d7c5d9437d30b81d842f266d35695e6b6942c4362cf82d09b3e`.

The first code-shrunk build omitted the resource package during optimization. The delivered package restores the binary resource archive generated by that build, aligns it, and signs it with the original debug key. Future builds disable the incompatible resource optimization step. Three focused unit tests passed (metadata fallbacks/preservation and Material scheme contrast); debug lint reported zero errors. The redesigned UI still requires Lynli's on-phone trial.
