# Validation

The first 106,004,738-byte APK was successfully tried on Lynli's phone. Its size included 68,434,456 compressed DEX bytes and 36,178,133 asset bytes. The asset pack accidentally included KYOTO twice. The source now contains exactly three M4As (about 23 MB), with matching embedded title, artist, album and artwork, and the full extended icon dependency has been replaced by selected vectors.

Version 0.2 is compiled with SDK 37.2/AGP 9.5.1 and requires Android 16. The distribution build uses R8 code shrinking, omits Compose preview tooling, and keeps the existing debug signing identity for update installation. Music is preserved without transcoding. Resource shrinking is disabled: the ARM64 packaging tool did not produce the optimized resource output required by AGP 9, and APK validation detected a missing manifest.

Build, lint, focused metadata tests, package/signing verification, and the download response are checked before distributing the updated APK. No ADB-connected device is available from proot. The revised visual layout, touch seeking, cover colors and permission refresh require a new on-phone trial.

The delivered 0.2.0 APK is 27,775,443 bytes (27.8 decimal MB). It has three unique M4As, a parsed Android manifest, a complete resource table, valid ZIP CRCs, aligned entries, and a verified APK v3 signature matching the first installed test APK. SHA-256: `cd18e50e4d080d7c5d9437d30b81d842f266d35695e6b6942c4362cf82d09b3e`.

The first code-shrunk build omitted the resource package during optimization. The delivered package restores the binary resource archive generated by that build, aligns it, and signs it with the original debug key. The 0.3 phone build helper explicitly disables resource optimization with `android.enableResourceOptimizations=false`; disabling resource shrinking alone was insufficient. Three focused unit tests passed (metadata fallbacks/preservation and Material scheme contrast); debug lint reported zero errors. The redesigned UI still requires Lynli's on-phone trial.

## Version 0.3.0

The phone helper completed `assembleRelease lintDebug testDebugUnitTest` successfully. All four focused tests passed: metadata fallbacks/preservation, generated Material scheme contrast, and neutral dark-surface contrast. Debug lint has 0 errors and 15 warnings.

The delivered APK is 29,301,993 bytes (29.3 decimal MB), includes exactly three starter M4As and the Roboto Flex display font, and requires/targets API 36. Manifest/resources and ZIP integrity pass verification, entries pass 16KB-page alignment checks, and its APK v2 signature matches the existing phone test signing certificate. SHA-256: `a02e070dd2ad092c84090dcd229ab1f11cd3d0b4808805981b893fe9920a9588`.

The resource optimization workaround is now verified through a full source build, with no manual resource restoration. Version 0.3.0 adds Home/collection layouts, the disabled Spotify placeholder, system-theme/album-colors-off defaults, neutral black dark surfaces and independently cover-colored mini players. The UI still needs Lynli’s on-phone trial; no device is connected through ADB.
