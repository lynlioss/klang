# Validation

The first 106,004,738-byte APK was successfully tried on Lynli's phone. Its size included 68,434,456 compressed DEX bytes and 36,178,133 asset bytes. The asset pack accidentally included KYOTO twice. The source now contains exactly three M4As (about 23 MB), with matching embedded title, artist, album and artwork, and the full extended icon dependency has been replaced by selected vectors.

It has three unique M4As, a parsed Android manifest, a complete resource table, valid ZIP CRCs, aligned entries, and a verified APK v3 signature matching the first installed test APK. SHA-256: `cd18e50e4d080d7c5d9437d30b81d842f266d35695e6b6942c4362cf82d09b3e`.

The first code-shrunk build omitted the resource package during optimization. The delivered package restores the binary resource archive generated by that build, aligns it, and signs it with the original debug key. The 0.3 phone build helper explicitly disables resource optimization with `android.enableResourceOptimizations=false`; disabling resource shrinking alone was insufficient. Three focused unit tests passed (metadata fallbacks/preservation and Material scheme contrast); debug lint reported zero errors. The redesigned UI still requires Lynli's on-phone trial.
